Informativa sulla privacy — Canali Studio

Ultimo aggiornamento: 7 novembre 2026.

Chi usa l'applicazione

Canali Studio è uno strumento privato usato solo dal titolare del canale YouTube Archivi Celati per gestire il proprio canale. Non è offerto a terzi e non raccoglie dati di altre persone.

Dati a cui accede

Con l'autorizzazione esplicita del titolare, l'applicazione usa le API di YouTube (YouTube Data API e YouTube Analytics API) per: caricare e programmare video sul canale del titolare, modificarne i metadati e le miniature, leggere le statistiche aggregate del canale.

Conservazione

I token di accesso restano solo sul computer del titolare. Nessun dato viene venduto, condiviso con terzi o trasferito a server dell'applicazione: l'applicazione non ha server propri.

Revoca

L'accesso può essere revocato in qualsiasi momento dalla pagina Autorizzazioni dell'account Google.

Servizi di Google

L'uso dei dati ricevuti dalle API di Google rispetta le Norme relative ai dati utente dei servizi API di Google, inclusi i requisiti di uso limitato, e i Termini di servizio di YouTube. Si applica anche l'informativa sulla privacy di Google.
